# Backgrounds

Бесшовные SVG-паттерны для UI и графики.

## Rules

- Tile seamlessly
- Default opacity guidance: **4–8%** on primary UI
- Use full strength only inside intentional industrial bars
- Prefer `currentColor` + CSS opacity for theming

## Files

| File | Notes |
|------|-------|
| `bg-grid-fine.svg` | Fine technical grid |
| `bg-dots.svg` | Dot matrix |
| `bg-diagonal-speed.svg` | Motion hatch |
| `bg-void-noise.svg` | Optional lore texture (keep subtle) |
