# Agent scenario: Slides

## Goal

Презентации и pitch-слайды в Graphic Realism.

## Canvas

- 16:9 (1920×1080) default
- Background: void `#0B0C0E` OR frost white `#F4F5F7`
- Never busy photography full-bleed without scrim

## Slide types

| Type | Structure |
|------|-----------|
| Title | Display 40–72px + thin hazard bar + mono ID |
| Section | CAPS label + large title |
| Bullets | max 4 lines, heavy hierarchy |
| Diagram | geometric nodes, cyan links |
| Quote / principle | huge type, one accent word |
| Closing | volt CTA bar + contact mono |

## Rules

1. **One idea per slide**
2. Margins ≥ 64px
3. Decals only on edges (corners, bottom hazard 8–16px)
4. Prefer 1 accent color per slide
5. Icons large (32–48) when used as pictograms
6. No paragraph walls — max ~30 words body
7. Page index mono bottom-right `03 / 12`

## Type scale (1920)

| Role | px |
|------|-----|
| Hero | 56–72 |
| Title | 40–48 |
| Body | 22–28 |
| Label | 14–16 CAPS |
| Mono meta | 14–16 |
