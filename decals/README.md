# Decals

Структурные и декоративные SVG-марки для chrome UI / slides / graphics.

## Kit

| File | Use |
|------|-----|
| `decal-hazard-stripe-45.svg` | Warning / industrial bar fill |
| `decal-hazard-stripe-bw.svg` | Black/white hazard |
| `decal-corner-registration.svg` | Viewfinder corners |
| `decal-bracket-frame.svg` | Technical brackets |
| `decal-accent-bar.svg` | 4px identity bar |
| `decal-status-pip.svg` | Status diamond/square |
| `decal-tick-ruler.svg` | Telemetry scale |
| `decal-diagonal-hatch.svg` | Subtle speed hatch |

## Rules

- Patterns must tile seamlessly when used as fill
- Background pattern opacity ≤ 8%
- Hazard bars: 8–16px tall strips, not full-bleed noise
- Prefer `currentColor` where single-ink
- No continuous animation on decals
- Faction/brand seals: original only + mono variant required
